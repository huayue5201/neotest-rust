1. INTRODUCTION                                      *neotest-rust-intro*

neotest-rust is a |neotest| adapter for Rust, using cargo-nextest.

This is a maintenance fork of rouge8/neotest-rust, which is no longer
maintained. It keeps the public configuration unchanged and only fixes
bugs; see |neotest-rust-fork| for the differences.

Requires nvim-treesitter and the Rust parser.

Supports standard library tests, rstest, Tokio's `#[tokio::test]`, and more.
Does not support rstest's parametrized tests.

==============================================================================
2. INSTALLATION                                    *neotest-rust-install*

>    require("neotest").setup({
      adapters = {
        require("neotest-rust")
      }
    })
<

==============================================================================
3. CONFIGURATION                                    *neotest-rust-config*

Pass additional arguments to `cargo nextest` via `args`: >
    require("neotest").setup({
      adapters = {
        require("neotest-rust") {
            args = { "--no-capture" },
        }
      }
    })
<
Pass environment variables to the test process via `env`: >
    require("neotest").setup({
      adapters = {
        require("neotest-rust") {
            args = { "--no-capture" },
            env = {
              RUST_LOG = "debug",
              RUST_BACKTRACE = "1",
            },
        }
      }
    })
<
Environment variables are passed through `spec.env` only; they are never
spliced into the command string.

==============================================================================
4. DEBUGGING TESTS                                      *neotest-rust-dap*

Codelldb is the default adapter used for debugging. Alternatives can be
specified via `dap_adapter`: >
    require("neotest").setup({
      adapters = {
        require("neotest-rust") {
            args = { "--no-capture" },
            dap_adapter = "lldb",
        }
      }
    })
<

==============================================================================
5. CHANGES IN THIS FORK                             *neotest-rust-fork*

- Removed the plenary.nvim dependency.
- Added the `env` option (see |neotest-rust-config|) and fixed `dap_adapter`
  handling.
- Panic/error parsing accepts both the old and new libtest panic formats
  and CRLF line endings.
- The nextest filter expression (`-E`) and the filterset are passed as
  separate arguments, so quotes are no longer interpreted as part of the
  filterset.

==============================================================================
6. LIMITATIONS                                      *neotest-rust-limits*

The following apply to both running and debugging tests.

- Assumes unit tests in `main.rs`, `mod.rs` and `lib.rs` are in a `tests`
  module.
- Does not support rstest's `#[case]` macro.
- When running tests for a `main.rs` in an integration test subdirectory
  (e.g. `tests/testsuite/main.rs`), all tests in that subdirectory will be
  run. Cargo cannot specify a single test file.

Additionally, when debugging, no output from failed tests is captured in the
results provided to Neotest.
